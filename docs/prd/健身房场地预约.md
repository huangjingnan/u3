# 产品方案：健身房场地预约小程序

> 纯前端实现 · 所有数据走 Mock · 适用于 unibest 微信小程序脚手架

## 一、一句话需求
帮健身房会员在线预约场地（跑步机、器械区、游泳馆等）的空闲时段，支持浏览场地、选时段预约、查看个人预约记录。

## 二、用户是谁
- 健身房会员（唯一用户角色）
- 没登录也能用（首次打开用昵称 + 头像占位即可）
- 一个人用，不需要多人协作

## 三、典型使用流程
打开小程序 → 看到场地分类 → 进某个场地看开放时段
→ 选一个空闲时段 → 填写手机号确认预约
→ 看到「预约成功」页面 → 之后从「我的预约」里查看/取消

## 四、核心功能

1. **首页（pages/index）**
   - 顶部 Banner：健身房名称、地址、营业时间
   - 场地分类入口：跑步机区 / 器械区 / 游泳馆 / 团课教室（图标 + 名称）
   - 快捷入口：「查看我的预约」

2. **场地列表（pages/venues）**
   - 按分类展示场地（如跑步机区下有多台跑步机可选）
   - 每条显示：场地名称、图片、开放时间、剩余可预约时段数
   - 标签：「可预约」/「已约满」

3. **场地详情（pages/venues/detail）**
   - 大图 + 场地介绍（文字 2~3 段）
   - 开放时间（例：06:00 - 22:00）
   - 底部固定按钮：「立即预约」

4. **预约时段（pages/book/time）**
   - 日历选择器（展示未来 7 天）
   - 时段网格（每 1 小时为一段，如 08:00-09:00）
   - 时段状态：可选（蓝色）/ 已约满（灰色）/ 已预约（绿色）
   - 底部固定按钮：「确认预约」

5. **预约确认（pages/book/confirm）**
   - 展示：场地名称、日期、时段、场地规则（如「超时需额外付费」）
   - 填写联系人：姓名、手机号
   - 底部固定按钮：「提交预约」（带安全区适配）

6. **预约成功（pages/book/success）**
   - 大图标「预约成功」
   - 展示预约信息：场地、日期、时段
   - 按钮：「查看我的预约」/ 「返回首页」

7. **我的预约（pages/orders）**
   - 时间倒序展示所有预约
   - 每条显示：场地名、日期时段、状态（待使用 / 已使用 / 已取消）
   - 点击进预约详情（pages/orders/detail）：完整字段 + 取消按钮（待使用时可取消）
   - 状态用 tag 颜色区分（蓝=待使用 / 灰=已使用 / 红=已取消）

8. **个人中心（pages/mine）**
   - 头像 + 昵称
   - 入口：「我的预约」→ 跳订单列表
   - 入口：「联系健身房」「关于我们」

## 五、Mock 数据约定
- **文件位置**：`my-app/src/utils/mock.js`
- **种子数据规模**：
  - 场地分类：≥ 4 个（跑步机区 / 器械区 / 游泳馆 / 团课教室）
  - 具体场地：≥ 8 个（每个分类 ≥ 2 个）
  - 时段：每个场地未来 7 天 × 14 段/天（06:00-22:00 每小时一段）
  - 历史预约：≥ 3 条（不同状态各 1 条）
- **统一请求层**：封装 `request(url, params)`，所有调用返回 Mock 数据
- **延迟模拟**：300~800ms 模拟网络体感

## 六、关键页面交互

| 页面 | 关键交互 |
|------|----------|
| 首页 | 顶部状态栏动态高度；分类图标点击进入对应场地列表 |
| 场地列表 | 下拉刷新；列表项点击进入详情 |
| 场地详情 | 大图懒加载；时段剩余数量实时显示 |
| 时段选择 | 日期切换后加载对应时段；时段单选；选中态高亮 |
| 预约确认 | 表单未填完禁用提交按钮；手机号格式校验 |
| 预约成功 | 弹窗 + 动画；自动跳转「我的预约」 |
| 我的预约 | 状态 tag 颜色区分；待使用可点击取消 |
| 个人中心 | 头像圆形，点击无操作（Mock） |

## 七、非功能性约束（来自 weapp-dev-workflow）
- 状态栏高度（动态获取）
- 底部安全区适配
- 机型覆盖自测

## 八、边界 / 不做的事
- 🚫 不做登录、不做鉴权、不做支付
- 🚫 不做真实定位（健身房地址用 Mock 数据）
- 🚫 不做后端 API、不接云函数、不上云
- 🚫 不做会员管理、不做签到、不做教练预约
- 🚫 不做消息推送
